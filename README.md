# superpoly

Discord bot which reads a zstd store of messages and posts a random message with premade image of the round attached. Made for [Yogstation13](https://github.com/yogstation13/Yogstation), which is long since dead, but the data (~1TB of images, ~2GB of compressed messages) was formed from its [replay archive](https://archive.org/details/yogstation_demos) (~120GB)
